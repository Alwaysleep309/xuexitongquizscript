
# 学习通自动刷题脚本——仅适用于不计分数的水课

脚本作用说明：

- 完成三种题型：判断题，多选题，单选题
- 方式是随机选择，所以不适用于需要分数标准的课程
- 自动刷题并切换章节
- 手动中断：在控制台内输入window._quizstop=true;
- 如果还未中断请叉掉控制台

## 文件说明
- [quiz.js](quiz.js)控制台直接执行

## 使用脚本注意事项：

### 开始使用前：

请确保自己登录网页版学习通，在课程的章节测试页面，然后再从控制台运行脚本

### 测验页面

脚本会自动跳过已完成的章节测验，并切入下一章节
章节测验页面可能会因为渲染过慢，卡在这一环节，超过等待时间
此时脚本会略过这一节，直接进入下一节测验
尽量重试

## 使用方法

1. 打开学习通课程播放页
2. 按 `F12`
3. 进入 `Console`
4. 复制 [quiz1.js](quiz1.js) 全部内容
5. 粘贴并执行
